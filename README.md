# SAE - Sistema de Agendamiento de Espacios y Equipos

Sistema web para gestionar y reservar espacios físicos y equipos dentro de una institución. Permite a usuarios consultar disponibilidad, agendar recursos y a administradores controlar el uso de los mismos.

## 🚀 Características principales

- **Reserva de espacios**: Salones, auditorios, laboratorios, canchas
- **Reserva de equipos**: Proyectores, portátiles, cámaras, micrófonos
- **Calendario en tiempo real**: Consulta disponibilidad por fecha y hora
- **Roles de usuario**: Estudiante, docente, administrativo, super admin
- **Aprobación de solicitudes**: Flujo de validación para reservas críticas
- **Historial y reportes**: Consulta reservas pasadas y genera estadísticas de uso
- **Notificaciones**: Confirmación y recordatorios por correo
